# ShareJack

Windows ve macOS arasında yerel dosya paylaşımı.

## İndir

[En güncel kurulum dosyaları](https://github.com/burakereno/sharejack-releases/releases/latest)

Bu depo resmi kurulum dosyalarını ve imzalı otomatik güncelleme manifestini barındırır. Kaynak kodu özel depoda tutulur.

0.1 sürümünü kullanıyorsanız güncelleme desteği için 0.2 sürümünü bir kez elle kurmanız gerekir. Sonraki sürümler uygulama üzerinden alınır. Dosya aktarımı sırasında uygulama yeniden başlatılmaz.
